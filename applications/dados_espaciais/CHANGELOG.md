# Changelog

## 0.1.0 — 2026-08-03

- pipeline genérico para dados espaciais e tabela de indicadores;
- validação de CRS, chaves, geometrias e colunas numéricas;
- reparo opcional de geometrias inválidas;
- junção um-para-um com limiar de cobertura;
- relatório de qualidade, arquivos de chaves não correspondidas e manifesto;
- cartografia por quantis ou intervalos iguais;
- base sintética offline e testes automatizados.
